# docs

## Purpose
補足ドキュメント群。API フロー図・ワークフロー可視化 HTML を格納する。ソースコードや設定ファイルとは独立した参照用ドキュメント。

## Key Files

| File | Description |
|------|-------------|
| `flows.json` | API フロー・データフローを記述した JSON（graphify 等の可視化ツール向け） |
| `workflows.html` | ワークフロー可視化の HTML ファイル |

## For AI Agents

### Working In This Directory
- このディレクトリのファイルはアプリの動作に影響しない（ランタイムには含まれない）
- `flows.json` を更新する場合は `workflows.html` も合わせて再生成すること
